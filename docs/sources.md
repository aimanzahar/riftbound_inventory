# Riftbound Inventory App — Source Map (all endpoints re-verified 2026-08-21)

Conventions: every source below returned 200 today unless stated. Nearly everything is undocumented/unofficial; send a browser-like `User-Agent` on all requests (several hosts 403 default UAs), keep QPS low, cache to SQLite, and refresh once per day.

## 1. Sources by dimension

### 1.1 Card data

**Primary — Riot Publishing Content Service (the official card-gallery feed; undocumented, no auth)**
- List: `https://content.publishing.riotgames.com/publishing-content/v2.0/public/channel/riftbound_website/list/riftbound_gallery_cards?locale=en_US&from=0&limit=200` — paginate `from`=0,200,…,1000 (`limit=2000` also returns all in one 3.24 MB response). Sets: `…/list/riftbound_gallery_sets?locale=en_US&from=0&limit=200` → `{data:[{id:"OGN",name:"Origins",collectorNumberMax:298},…]}`.
- Shape: `{data:[{id:"unl-131-219", collectorNumber:131, publicCode:"UNL-131/219", name:"Abandon", set:{value:{id:"UNL",label:"Unleashed"}}, cardType:{type:[{id:"spell",label:"Spell"}], superType:[{id,label}]}, rarity:{value:{id:"uncommon",label}}, domain:{values:[{id:"chaos",label:"Chaos"}]}, cardImage:{url:"https://cmsassets.rgpub.io/sanity/images/dsfx7636/game_data_live/<sha1>-744x1039.png?accountingTag=RB", dimensions:{width,height}, accessibilityText, colors}, orientation, illustrator:{values:[{id,label}]}, text:{richText:{type:"html",body}}, energy:{value:{id}}, might, power, mightBonus, effect:{richText}, tags:{tags:[]}}], metadata:{totalItems:1197,totalPages,from,limit,resultsUpdatedAt}, linkdata:{first,last,next,self}}`.
- Coverage: 1189 unique cards (OGN 352, OGS 24, SFD 288, UNL 288, VEN 237); metadata claims 1197 (8 unexplained). Domains: fury, calm, mind, body, chaos, order, colorless. Types: Unit/Spell/Legend/Gear/Battlefield/Rune; supertypes Champion/Signature/Basic/Token; rarities Common/Uncommon/Rare/Epic/Showcase. Rules text is PRINTED (not errata'd) with `:rb_energy_N:`/`:rb_rune_*:`/`:rb_exhaust:` tokens. No flavor text, no promo sets (PR/OPP/JDG).
- Caveats: `Cache-Control: no-cache`; Python urllib default UA → 403. Riot "Legal Jibber Jabber" fan policy + Riftbound Digital Tools Policy (galleries/deckbuilders OK; no automated rules enforcement; official App approval requires Riot-API assets only).

## 2. Canonical card-id scheme and set list

**Recommended primary key = the gallery `id`**: `{set}-{nnn}{variant}-{setTotal}` lowercase, e.g. `ogn-001-298`; `publicCode` is the printed form `OGN-001/298`.

| Variant | gallery id | publicCode | short code seen elsewhere |
|---|---|---|---|
| Alt art / Showcase | `ogn-007a-298` (`b` = 2nd alt) | `OGN-007a/298` | `OGN-007a` (Piltover, dotgg, RiftScribe `variant:"a"`) |
| Signature | `ogn-304-star-298` | `OGN-304*/298` | `OGN-304s` (Piltover CDN, riftmana, riftbound-db, Scrydex), `OGN-304-STAR` (dotgg), `OGN-304*` (Piltover API), `unl-229*-219` (Riftcodex) |
| Overnumbered showcase | collectorNumber > set max (`ogn-299-298`…`ogn-310-298`) | `OGN-299/298` | `OGN-299` |
| Token | `unl-t01` | `UNL-T01` | `UNL-T01`, back `UNL-T01.2` (dotgg) |
| Rune | `ven-r01` (alt `VEN-R02a`) | — | `VEN-R01` |
| Special/crossover | `ven-sp1-006` | `VEN-SP1/006` | `VEN-SP1`, `VEN-SP1a` |
| Promo reprints | Riftcodex `pr-246a-298`, `pr-246b-298`, `opp-001-024/-219/-298` (promo sets reuse base number+total) | — | dotgg `OGN-066-P`, `UNL-T02-P`; riftmana `OGN-001-p` |

## 4. Deck rules (Core Rules 2026-07-16 + Tournament Rules 7/16/2026)
- 1 Champion Legend (sets Domain Identity, normally 2 domains).
- Main Deck ≥40 casual / **exactly 40 constructed**, including the Chosen Champion (a Champion Unit whose champion tag matches the Legend). Max 3 copies per card NAME (incl. Chosen Champion; counts across main + sideboard). Max 3 Signature cards total, all must carry the Legend's champion tag. Every card's domains ⊆ identity (Colorless always legal).
- Rune Deck exactly 12, all within identity. Exactly 3 Battlefields with unique names (1v1). Sideboard 10 or fewer (older 2026 docs: exactly 0 or 8 — confirm against live TR). Full constructed deck = 56 + ≤10 side.
- Standard: OGS, OGN, SFD, UNL, VEN; yearly rotation planned from 2028. Banned (hub, 2026-07-16): Called Shot, Draven Vanquisher, Fight or Flight, Scrapheap, Stealthy Pursuer; battlefields The Arena's Greatest, Aspirant's Climb, Dreaming Tree, Obelisk of Power, Reaver's Row; 2v2-only ban: Master Yi, Wuju Bladesman.
- Sealed: 6 boosters, main ≥25, identity = any 3 domains or legend's domains +1, no copy limits, legend/champion optional, blank battlefields. Draft: 3 boosters, main ≥20, same relaxations. 2v2: constructed or 8-pack shared sealed; 11 points.
